# PriorOcc-4D 实验结论归档

本目录汇集 2026-10-19 ~ 10-21 期间 PriorOcc-4D（单流 `smp-sdp-holefill-nodepth`）全部评测产物，供离线分析。

## ⚠️ 读数字前必看：口径三要素
任何两个 mIoU 只有在**三项全部一致**时才能比大小：
1. **评测样本集**：全量 `4818`（forecast 可用帧）/ 全量 `6019`（单帧 val 全量）/ `300` 跨场景子集；
2. **权重类型**：`epoch_N_ema.pth`（EMA）vs `epoch_N.pth`（非 EMA），EMA 实测高约 **+2**；
3. **模型/任务**：4D 当前帧 vs 专职单帧。

已实测的口径代价：同一模型换抽样口径（前 300 连续 vs 跨场景 300）当前帧差 **3.4**；同 ckpt 非 EMA→EMA 差 **+2.24**。

## 三、三组对照裁决（ep19_ema，全量 4818，同一次推理）
| arm | 1s dyn | 2s dyn | 3s dyn | 1s all | 2s all | 3s all |
|---|---|---|---|---|---|---|
| MODEL（完整运动预测） | **11.02** | 6.66 | 4.79 | **21.26** | **16.99** | **14.59** |
| B档（冻结模型自身当前帧） | 9.92 | **6.88** | **5.58** | 18.74 | 14.95 | 13.07 |
| GT-copy（冻结 GT 当前帧，参照） | 13.58 | 9.74 | 8.05 | 19.67 | 14.72 | 12.39 |

- 动态 Δ(MODEL−B档) = **+1.11 / −0.22 / −0.79** → **1s 短时程运动建模有正贡献，2s/3s 因自回归误差累积转负**。
- 整体 mIoU 三 horizon 全面优于冻结 → 4D 预测整体有效。
- 误差分解：感知代价（GT-copy − B档，1s）= **3.66** > 运动增益 **1.11** → **瓶颈排序：感知 > 长时程运动建模**。
- GT static-copy 整体基线：`19.67 / 14.72 / 12.39`（动态 13.58/9.74/8.05、静态 28.37/21.85/18.59）。

## 五、根因结论（当前帧低于单帧 ep21）
1. **多任务税**：`loss_occ` 权重 1.0，而未来三项合计 2.2 + 3×2D seg 各 1.0 + 先验正则 → 当前帧只占小头，且 occ_head 同时服务当前与未来。
2. **BEV 入口重构**：`img_bev_encoder_backbone` 首层因时序拼接 192 vs 64 通道被重初始化；证据 ep1=30.42 → ep15=32.10（+1.68）后走平。
3. **训练帧数少 20%**：`train_forecast.pkl` 仅 **22522** 帧可用（vs 单帧 **28130**），每场景首 2 + 尾 6~7 帧被排除（11261 iter/epoch = 22522÷2 吻合）。
4. **batch 2 vs 4**：梯度噪声更大，稀有类每 batch 命中更少。
5. 上述均为结构性代价，**实测不会靠继续训练缩小**。

## 六、修复版短训（进行中，`work_dirs/smp-fix-v1`）
配置 `projects/configs/priorocc/priorocc-4d-r50-smp-sdp-holefill-fix.py`，`load_from=epoch_15_ema.pth`，12 轮、`lr step=[8]`：
1. **非自回归**：每个 horizon 都对同一当前 BEV 做 warp，消除 2s/3s 误差累积；
2. **逐 horizon flow 上限 [12, 24, 36] cells**（原全局 5 cells = 2.56 m；GT 动态位移 p90 ≈ 8.6/14.1/17.9 cells）；
3. **gate 初始化偏向 warp**（bias=2.0 → α≈0.88），起步不低于冻结基线。

参数量 59.485M 不变，与 ep15_ema 权重 0 缺失 / 0 多余 / 0 形状失配。
**验收判据**：动态 IoU 在 2s/3s 由负转正（超过 B 档 6.88 / 5.58），且整体不低于 21.34 / 17.14 / 14.77。
